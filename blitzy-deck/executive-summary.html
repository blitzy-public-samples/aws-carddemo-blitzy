Data Tier

VSAM indexed files to PostgreSQL 16

VSAM DatasetPostgreSQL TableKey / Index / FK
CUSTDATA.KSDScustomerPK cust_id
ACCTDATA.KSDSaccountPK acct_id; group_id grouping attribute (no FK — disclosure_group PK is composite)
CARDDATA.KSDScardPK card_num; index acct_id (AIX); FK acct_id
CARDXREF.KSDScard_xrefPK xref_card_num; index acct_id (AIX); FK cust_id, acct_id
TRANSACT.KSDStransactionPK tran_id; index proc_ts (AIX, AXRKP=304); FK card_num, type_cd, composite (type_cd, cat_cd)
USRSEC.KSDSuser_securityPK sec_usr_id
TRANTYPEtransaction_typePK type_cd
TRANCATGtransaction_categoryPK (type_cd, cat_cd)
DISCGRPdisclosure_groupPK (group_id, type_cd, cat_cd); int_rate DECIMAL(6,2)
TCATBALFtran_cat_balancePK (acct_id, type_cd, cat_cd); bal DECIMAL(11,2)

3 alternate indexes become B-tree indexes (the transaction AIX keys on the processing timestamp, proc_ts); application-enforced relationships become real foreign keys where the parent key is unique — account.group_id stays a grouping attribute resolved by composite lookup; every COMP-3 field becomes DECIMAL(x,2).
