Risks & Mitigations

Flagged openly, each with a mitigation or suggested next step.

Risk Severity Mitigation / next step
Spring Boot 3.5 OSS end-of-life 2026-06-30. Chosen to honor “Spring Boot 3.x latest stable” (3.5.16, the final 3.x). An EOL branch gets no future CVE patches, which interacts with the OWASP zero critical/high gate. Elevated Upgrade to Spring Boot 4.x — suggested next task.
Cleartext-password parity. The legacy password-comparison behavior is preserved for functional parity; hardcoded credentials are removed in favor of externalized configuration (environment variables). Elevated Introduce BCrypt password hashing — suggested next task.
Runtime toolchain currency. The application dependency graph passes the OWASP critical/high gate, but the pinned JDK build carries published advisories; a newer patch release resolves them but was not installable in the offline build environment. Elevated Adopt the next JDK patch release — tracked as a next task.
Concurrency & duplicate-key parity. The legacy locked records under update (online CICS READ … UPDATE and the posting job’s dataset ENQ) and abended on a duplicate write. Both are reproduced with row-level pessimistic locks and a true-INSERT duplicate-key abend, preserving the 0 / 4 / 8 RETURN-CODE contract. Hardened Fixes in place, proven by multi-thread parity tests (ConcurrencyParityIT) — parity preserved, not assumed.
Scope discipline — no feature expansion. MQ/JMS, Db2, IMS, FTP/SFTP, REST/SOAP APIs and a CI/CD pipeline are intentionally out of scope. By design Listed as future work — never presented as delivered.
