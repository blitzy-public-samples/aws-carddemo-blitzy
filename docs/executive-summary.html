Flow 1

Sign-on, then authenticated account inquiry

sequenceDiagram
  autonumber
  participant C as HTTP client
  participant R as Router COAPIRTR
  participant S as Auth COAPISEC
  participant T as MAIN TSQ registry
  participant A as COACSVCC
  C->>R: POST sign-on (user id + password)
  R->>S: validate credentials vs USRSEC
  S->>T: register short-lived token (15-min life)
  S-->>R: bearer token
  R-->>C: 200 token issued
  C->>R: GET account by id + bearer token
  R->>S: validate token
  S->>T: look up token (unknown/expired to 401)
  S-->>R: token accepted
  R->>A: read ACCTDAT (read-only)
  A-->>R: account record
  R-->>C: 200 JSON account

The Contract

Seven read-only endpoints

The seven read-only REST endpoints with method, path, and purpose.
MethodPathPurpose
POST/carddemo/api/v1/signonAuthenticate; issue bearer token
GET/carddemo/api/v1/accounts/{acctId}Status, balances, limits, dates
GET/carddemo/api/v1/customers/{custId}Demographics (PII minimized)
GET/carddemo/api/v1/cards/{cardNum}Detail (PAN masked, CVV excluded)
GET/carddemo/api/v1/xref/{cardNum}Card to account + customer
GET/carddemo/api/v1/accounts/{acctId}/transactionsList account transactions
GET/carddemo/api/v1/transactions/{tranId}Single transaction

Security

Sensitive data protected by default

PAN masked to last 4
CVV never returned
SSN & gov-id masked
Bearer token vs USRSEC
  • Uniform error envelope and a fixed HTTP status map.

Risks & Mitigations

Managed Risk

Known risks, deliberate mitigations

Known risks and their deliberate mitigations.
RiskMitigation
Cleartext HTTP, no transport auth yetLoopback-only listener; TLS/keyring and RACF documented follow-up
Stateless pseudo-conversational CICSToken registry in a MAIN TSQ, short 15-minute life
No card or account transaction indexApplication-level filtering; pagination and index later
Oversized transaction-list payloadsCICS channel/container transport, not COMMAREA
Sensitive PII exposurePAN last-4, CVV omitted, SSN/gov-id masked by default
Deck CDN supply-chain integrityPinned CDN versions with SRI + CSP; static author-only diagrams (decision-log D40)
