Executive Summary • March 2026

📋 The Application

CardDemo — AWS Mainframe Sample

Open-source Credit Card Management System (Apache 2.0, Q4 2022). Two user roles — Administrator and Regular User. Built for migration and modernization tooling validation.

💻 28 COBOL Programs
(18 online + 10 batch)
🖥️ 17 BMS Screen Maps
📄 28 Copybooks
(shared data definitions)
🗃️ 10 VSAM Datasets
(+ 3 alternate indexes)

🎯 Why Now?

🔧

Maintainability

COBOL talent pool is shrinking. Java developers are significantly more available, reducing long-term staffing risk.

💰

Reduced TCO

Eliminate mainframe licensing costs (CICS, VSAM, z/OS). Run on commodity hardware and open-source infrastructure.

🚀

Agility

Modern CI/CD pipelines, automated testing with JUnit 5 and Testcontainers, and faster release cycles.

🔒

Security

Replace plaintext password storage with BCrypt hashing. Externalize all credentials via environment variables.

🔒 Security Enhancements

🔓 Before (COBOL)

  • Plaintext passwords (SEC-USR-PWD PIC X(08))
  • RACF-based authentication
  • Hardcoded credentials in JCL
  • No role annotations

🔒 After (Java)

  • BCrypt-hashed passwords
  • Spring Security RBAC
  • Environment-variable credentials
  • @PreAuthorize role annotations
Login Request → BCrypt Verify → Role Assignment (ADMIN / USER) → Session → Secured Endpoints

Deliberate deviation from COBOL behavior — documented in decision-log.md (DEC-003).

⚠️ Risks & Mitigations

Business logic regressionFunctional parity loss during translation
Mitigation100% traceability matrix + ≥80% test coverage
Decimal arithmetic driftRounding differences in monetary calculations
MitigationBigDecimal with RoundingMode.HALF_UP matching COBOL COMP-3
Feature expansion creepUnplanned additions beyond COBOL scope
MitigationStrict AAP boundary enforcement — no new screens, reports, or fields
External interface breakageConsuming systems rely on output formats
MitigationFixed-width file format preservation for DALYREJS and statements
Database behavior differencesPostgreSQL vs VSAM semantics
MitigationTestcontainers with real PostgreSQL 16+ (not H2 mock)
Concurrent access conflictsOptimistic locking mismatch
MitigationJPA @Version optimistic locking (replaces CICS READ UPDATE)
