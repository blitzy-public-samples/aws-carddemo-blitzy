Welcome to CardDemo API

This API documentation provides interactive testing capabilities for all 17 REST endpoints that replace the original mainframe CICS transactions. The API enables modern web and mobile applications to access credit card management functionality previously available only through 3270 terminal screens.

🔄 Mainframe to Cloud Transformation

These REST APIs maintain functional equivalence with the original COBOL programs while providing modern JSON-based interfaces for web applications, replacing the BMS 3270 terminal screens with React components. Every endpoint preserves the exact business logic, validation rules, and data integrity constraints of the original mainframe implementation.

API Endpoints Quick Reference

Authentication

  • POST /api/auth/login Replaces CC00 (COSGN00C)
  • POST /api/auth/logout Session termination

Menu Navigation

  • GET /api/menu Replaces CM00 (COMEN01C)
  • GET /api/admin/menu Replaces CA00 (COADM01C)

Account Management

  • GET /api/accounts/{id} Replaces CAVW (COACTVWC)
  • PUT /api/accounts/{id} Replaces CAUP (COACTUPC)

Card Operations

  • GET /api/cards Replaces CCLI (COCRDLIC)
  • GET /api/cards/{id} Replaces CCDL (COCRDSLC)
  • PUT /api/cards/{id} Replaces CCUP (COCRDUPC)

Transaction Management

  • GET /api/transactions Replaces CT00 (COTRN00C)
  • GET /api/transactions/{id} Replaces CT01 (COTRN01C)
  • POST /api/transactions Replaces CT02 (COTRN02C)

Billing & Payments

  • POST /api/billing/payment Replaces CB00 (COBIL00C)

Reporting

  • GET /api/reports/transactions Replaces CR00 (CORPT00C)

User Administration

  • GET /api/admin/users Replaces CU00 (COUSR00C)
  • POST /api/admin/users Replaces CU01 (COUSR01C)
  • PUT /api/admin/users/{id} Replaces CU02 (COUSR02C)
  • DELETE /api/admin/users/{id} Replaces CU03 (COUSR03C)

🔒 Authentication Required

Most endpoints require JWT Bearer token authentication. Obtain a token by calling POST /api/auth/login with valid credentials. Include the token in the Authorization header: Authorization: Bearer <your-token>
